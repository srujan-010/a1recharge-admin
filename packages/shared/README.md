# @a1recharge/shared

Shared types and utilities for the A1 Recharge monorepo.

## Usage

```typescript
import { Retailer, WalletTransaction, AppSettings } from '@a1recharge/shared';
```

## Exports

- **Retailer** - User/retailer interface
- **WalletTransaction** - Financial transaction model
- **AppSettings** - Application settings
- **CommissionProfile** - Commission rate and structure
- **BankAccount** - Bank account details
- **KycStatus** - KYC verification status types
- **UserRole** - Admin user role types
- **AuditAction** - Audit log action types
- **AuditLogEntry** - Audit log entry interface
- **TransactionType** - Financial transaction type

## Building

Run `npm run build` to compile TypeScript to JavaScript.

## Versioning

Follow semantic versioning across the monorepo.
